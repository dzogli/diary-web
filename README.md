# Мой дневник для Android (версия 2.1)

APK собирается бесплатно в облаке GitHub, ставить Android Studio не нужно.

## Обновление (репозиторий diary-android у вас уже есть)

1. Распакуйте этот архив.
2. Откройте ваш репозиторий `diary-android` на github.com. Нажмите **Add file -> Upload files**.
3. Выделите ВСЁ внутри распакованной папки (кроме папки `.github`: она у вас уже загружена) и перетащите в окно браузера.
   Файлы с теми же именами заменятся. Нажмите **Commit changes**.
4. Откройте вкладку **Actions**. Сборка запустится сама и займёт 5-10 минут. Дождитесь зелёной галочки.
5. Откройте запуск (верхний в списке), внизу в разделе **Artifacts** скачайте **Diary-APK**.
   Внутри zip лежит `app-release.apk`.
6. Перенесите APK на телефон и откройте его. Ставьте ПОВЕРХ старой версии: подпись та же, записи сохранятся.

## Первая установка (если репозитория ещё нет)

1. На github.com: «+» -> New repository -> имя `diary-android` -> **Private** -> Create.
2. «uploading an existing file» -> перетащите всё содержимое распакованной папки, кроме `.github`. Commit changes.
3. Add file -> Create new file. В имени введите `.github/workflows/android.yml` и вставьте текст из файла `.github/workflows/android.yml` этого архива. Commit.
4. Дальше как в пунктах 4-6 выше.

## После установки

- **Уведомления.** Настройки -> «Разрешить уведомления» -> разрешите уведомления и «Будильники и напоминания». Тогда напоминания приходят вовремя, даже когда приложение закрыто.
- **Синхронизация.** Настройки -> «Синхронизация между устройствами»: те же адрес проекта, ключ, email, пароль аккаунта и пароль шифрования, что на компьютерах, кнопка «Войти».
- **Копии.** «Сохранить копию» открывает меню «Поделиться» (Google Диск, Telegram, Файлы). «Восстановить из копии» предлагает выбрать файл.
- **Кнопка «Назад»** закрывает панели и диалоги, возвращает в проект или «Мой день», на главном экране сворачивает приложение.
- **Оформление.** Настройки -> «Оформление»: «Как на устройстве», «Светлая» или «Тёмная». По умолчанию светлая, как на Windows. Цвет строки состояния меняется вместе с темой.
- Репозиторий держите **приватным**: в нём лежит ключ подписи приложения.
